# 🎓 DegreEZ

**Your Smart Academic Companion for Technion Students**

DegreEZ is an all-in-one academic assistant designed specifically for Technion students. It simplifies the complexity of degree planning by combining intuitive schedule visualization, real-time progress tracking, and AI-powered tools — all wrapped in a sleek, personalized experience.

---

## 💡 Motivation

Navigating university life shouldn't feel like solving a puzzle blindfolded.

Currently, Technion students lack dedicated tools to help them manage their academic journey effectively. Common struggles include:

- **Scheduling conflicts** — juggling overlapping courses and events
- **Unclear degree paths** — uncertainty about which courses to take and when
- **Prerequisite confusion** — difficulty tracking what's required before enrolling
- **GPA planning** — no easy way to simulate grade outcomes
- **Information overload** — scattered resources with no centralized hub

**DegreEZ was built to change that.** We give students the clarity, control, and confidence they deserve — transforming academic planning from a chore into a breeze.

---

## ✨ Core Features

| Feature | Description |
|--------|-------------|
| 👤 **Personalized Profile** | Securely backed-up student profiles storing all relevant academic details |
| 🗓️ **Smart Calendar** | Visual weekly and daily views for scheduled courses and personal events |
| 📎 **Interactive Course Diagram** | A fully customizable flowchart of your entire academic path — from first semester to graduation — showing prerequisites, current progress, and future plans |
| 🧠 **AI-Powered Recommendations** | Intelligent course suggestions based on your interests, academic history, and available time |

---

## 🛠️ Complementary Features

| Feature | Description |
|--------|-------------|
| 🌐 **Campus Map Integration** | Interactive Technion map with live location tracking and building highlights based on your courses |
| 🚦 **Conflict Detection** | Visual warnings for scheduling conflicts (non-blocking, so you stay in control) |
| 🔗 **Prerequisite Viewer** | Select any course to instantly see its prerequisites displayed with visual arrows or a clear list |
| 📊 **GPA Calculator & What-If Simulator** | Experiment with grade scenarios (e.g., *"What if I get 90 in Algorithms?"*) to preview your GPA changes in real-time |
| 💬 **AI Chat Assistant** | Ask natural questions like *"Which course gave me the lowest grade?"* or *"What should I take next semester?"* |
